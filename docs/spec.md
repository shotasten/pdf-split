# PDF見開き分割くん 仕様

## 概要

PDF見開き分割くんは、見開きで作られたPDFを1ページずつに分割するWebアプリです。ユーザーが選択したPDFをブラウザで読み込み、分割後のPDFをその場で生成します。

処理の中心は [app/pdf-split-app.tsx](../app/pdf-split-app.tsx) です。

## 対象ユーザー

- 見開きスキャンされたPDFを単ページのPDFに直したい人
- 左右綴じ、右左綴じ、上下分割の向きを手元で確認しながら変換したい人
- PDFを外部サービスへアップロードせずに処理したい人

## 主要機能

- 複数PDFファイルの読み込み
- 複数ファイル選択とドラッグアンドドロップに対応する
- MIME type が `application/pdf`、または拡張子が `.pdf` のファイルを受け付ける
- 一覧から選択したPDFのPDF.jsによるプレビュー表示
- パスワード付きPDFでは、パスワード入力欄を表示して正しいパスワードで読み込む
- 複数ページPDFのページ送り
- 分割位置の表示
- 左右分割と上下分割の切り替え
- 出力順の切り替え
- 1ファイルはPDF形式、複数ファイルはZIP形式でのダウンロード
- 一覧からの個別PDF削除と、読み込んだPDFの一括クリア

## 分割設定

分割方向は2種類です。

- 左右に分割
- 上下に分割

分割位置は20%から80%の範囲で指定します。ステップは0.5%。50%の近くでは中央に吸着し、`49%` から `51.5%` の範囲は `50%` として扱います。

出力順は分割方向によってラベルが変わります。

- 左右分割の通常順は左ページから
- 左右分割の逆順は右ページから
- 上下分割の通常順は上ページから
- 上下分割の逆順は下ページから

読み込んだすべてのPDFには、同じ分割方向、分割位置、出力順を適用します。ファイルごとの設定変更には対応しません。プレビューするファイルは一覧から切り替えられます。

## PDF生成

PDF生成には `pdf-lib` を使います。元PDFの各ページを2回ずつ複製し、分割範囲に合わせてページボックスを設定します。

設定するページボックスは以下です。

- `MediaBox`
- `CropBox`
- `BleedBox`
- `TrimBox`
- `ArtBox`

ページ内容を画像に変換してからPDF化する方式ではありません。元ページを複製し、表示範囲を切り出す方式です。

ただし、パスワード付きPDFは `pdf-lib` で復号してページを複製できないため、PDF.jsでブラウザ内に描画したページを分割して画像PDFとして生成します。出力PDFにはパスワードを設定せず、文字の選択やベクター情報は保持されません。

## PDFの回転情報の扱い

分割時は、元ページに設定されている回転角を読み取ります。`0`、`90`、`180`、`270` 度の回転角を正規化し、分割範囲をPDFページの座標へ変換します。

これはユーザーが画面で回転を指定する機能ではありません。回転情報を持つPDFでも、分割範囲が見た目から大きくずれないようにするための内部処理です。

## プレビュー

プレビューには `pdfjs-dist` を使います。

- 読み込み直後は1ページ目を表示する
- パスワード付きPDFではパスワードを入力してからプレビューを表示する
- プレビュー領域の幅に合わせて縮小する
- デバイスピクセル比を使ってcanvasを描画する
- 分割方向と分割位置に合わせてマーカーを表示する

複数ページのPDFでは「前へ」「次へ」でプレビュー対象ページを切り替えます。分割処理自体は、プレビュー中のページだけでなく全ページを対象にします。

## ファイル名

各PDFの出力ファイル名は、元ファイル名の `.pdf` を取り除いた末尾に `-split.pdf` を付けます。1ファイルだけを処理した場合は、そのPDFを直接ダウンロードします。複数ファイルを処理した場合は、成功分をまとめたZIPファイルを `split-pdfs.zip` としてダウンロードします。

例: `book.pdf` から生成した場合は `book-split.pdf`

元ファイル名が取得できない場合は `split.pdf` を使います。

処理は1ファイルずつ順番に行い、処理中・完了・失敗の状態を一覧に表示します。複数ファイルの処理で失敗したファイルがあっても、成功したファイルはZIPに含めます。

## エラー表示

現在の主なエラーは以下です。

- PDF以外のファイルが選択された
- PDFのプレビュー生成に失敗した
- PDFの分割に失敗した
- PDF未選択の状態で分割が実行された
- バッチ内の個別PDFの分割に失敗した

パスワードが違うPDF、破損したPDFは、プレビューまたは分割に失敗する場合があります。パスワード付きPDFをバッチ処理する前には、一覧で対象ファイルを選択してパスワードを入力します。

## プライバシー

PDFの読み込み、プレビュー、分割PDFの作成はブラウザ内で行います。選択されたPDFと入力したパスワードをアプリケーション側のサーバーへ送る処理はなく、パスワードは保存しません。

`NEXT_PUBLIC_GA_ID` が設定されている環境では、サービス改善のために Google Analytics を読み込み、ページビューなどのアクセス状況を計測します。PDFファイルの内容を Google Analytics へ送信する処理はありません。未設定の場合、Google Analytics のタグは出力されません。

Google AdSense の自動広告タグは `APP_ENV=prd` のときのみ全ページの `<head>` に出力します。Cloudflare Pages の Production 環境に `APP_ENV=prd` を設定し、Preview やローカルでは未設定のままにします。広告配信では Cookie などが利用される場合がありますが、PDFファイルの内容を Google AdSense へ送信する処理はありません。

プライバシーポリシーは [app/privacy/page.tsx](../app/privacy/page.tsx) にあります。

## 技術構成

- Next.js
- React
- TypeScript
- pdf-lib
- pdfjs-dist
- ESLint

`next.config.ts` では `output: "export"` と `images.unoptimized: true` を設定しています。

Google Analytics は `app/layout.tsx` で `next/script` を使って読み込みます。トラッキングIDは `NEXT_PUBLIC_GA_ID` から参照します。

Google AdSense は `app/layout.tsx` で自動広告タグを読み込みます。クライアントIDは `ca-pub-5169510031090776` です。読み込み条件は `APP_ENV=prd` です。

## 実装上の注意

- PDFの分割ロジックを変えた場合は、この仕様書も更新する
- UIの文言や操作フローを変えた場合は、READMEと仕様書の両方を確認する
- PDF処理をサーバーへ移す変更を入れる場合は、README、仕様書、プライバシーポリシーの更新が必要
- アクセス解析や外部サービス連携を変更する場合は、README、仕様書、プライバシーポリシーの更新が必要
- ページ回転や座標変換を変更する場合は、左右分割、上下分割、逆順出力をまとめて確認する
